# 用户意图

## 目标用户
本文档主要面向对 Agent Memory（智能体记忆）技术感兴趣的以下人群：
- **研究人员**：需要查找相关论文、基准测试和前沿研究进展
- **开发者**：需要寻找可用的开源产品和工具来实现记忆功能
- **学习者**：希望系统性了解 Agent Memory 领域的技术体系和发展趋势
- **技术决策者**：需要评估和选择合适的记忆系统方案

## 使用场景
- 研究人员查找特定领域的最新论文和研究成果
- 开发者寻找合适的开源记忆系统来集成到自己的 AI Agent 项目中
- 学习者了解 Agent Memory 的技术分类、主要方法和应用场景
- 需要查找相关的教程、调研报告、基准测试数据集等学习资源
- 对比不同记忆系统的特点、功能和技术路线

## 文档侧重点
本文档采用**单篇详细资源指南**的形式：
- 生成一篇完整的文档，比原 README 更详细
- 包含领域概述、技术分类说明、资源详细介绍
- 为每个资源类别添加更详细的说明和背景
- 添加技术发展脉络和研究趋势分析
- 提供更清晰的导航和章节组织
